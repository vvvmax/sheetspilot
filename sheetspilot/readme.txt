== Description ==

**SheetsPilot turns WordPress into a powerful spreadsheet editor for posts, products and SEO.**  
Instead of opening dozens of edit screens, you can work with all your content in one familiar grid.  Each row is a post or product and every column is a field, taxonomy, custom field or SEO meta value.  Edits save instantly through WordPress; there's no export/import step.

**<a href="https://sheetspilot.ai/">Upgrade to SheetsPilot Pro to get AI Unlimited Power</a>**

Use SheetsPilot to perform large-scale updates on WooCommerce catalogs, bulk edit Yoast SEO metadata, manage Advanced Custom Fields (ACF) and events, and even generate copy with a built-in AI assistant.  It is ideal for store owners, content teams, freelancers and agencies who need to manage hundreds or thousands of records efficiently.

For everyday tasks it offers column editing for your admin columns: sort any column ascending or descending, filter your content using stackable smart filters, add any column to posts, pages, users, media or comments, reorder and resize columns, and edit values inline or in bulk.  SheetsPilot wraps these features into a full spreadsheet interface with AI and deep SEO integrations.

If you're searching for a flexible admin columns manager, SheetsPilot provides all the column customization features plus a full spreadsheet interface and AI-powered workflow tools.

Turn your WordPress admin into a WP Sheet Editor with AI-powered bulk editing or deeper SEO integrations, SheetsPilot is a compelling upgrade that works as a WP Sheet Editor alternative.

**Key features**

- **Spreadsheet editing for posts and pages:** view titles, statuses, categories, tags and more in a single grid. Filter and sort to find the content you need. Update values inline or copy/paste between cells.
- **WooCommerce bulk editor:** adjust regular and sale prices, SKU codes, stock, categories, attributes and images across hundreds of products at once. Manage variable products, their variations and custom attributes directly in the grid (perfect for WooCommerce spreadsheet pricing tasks).
- **SEO metadata editor:** audit and bulk edit SEO titles, descriptions and focus keywords for **Yoast SEO**, **Rank Math** and **SEOPress**. Quickly fill missing fields and ensure your posts follow best practices. Great for those looking for a Yoast SEO bulk editor.
- **Advanced Custom Fields (ACF) support:** display ACF groups and subfields as columns so you can edit custom post types and complex data quickly, including ACF for WooCommerce products.
- **Events management:** edit The Events Calendar events en masse, including dates, venues, organizers and ticket prices.
- **Built-in AI assistant:** generate product descriptions, meta titles, meta descriptions and summaries using OpenAI. Save reusable prompts, apply them to selected fields and run them in bulk.
- **Smart filters and bulk actions:** filter content with stackable smart filters that can combine status, taxonomy, price, SKU or any field value; select all results and apply changes or AI prompts across them; undo actions if needed.
- **Flexible column management:** add any column to posts, pages, users, media or comments and choose which columns to display on products or custom post types; display custom fields, taxonomies, images, file data and other metadata; reorder columns by drag-and-drop and resize them to match your workflow; create column sets for different tasks and switch between them.
- **Powerful sorting and filtering:** sort any column in ascending or descending order and apply multi-condition smart filters to find the exact posts, products or events you need; stack multiple filters to create complex queries and narrow your results.
- **Inline and bulk editing:** edit titles, custom fields, taxonomies, prices and other values directly from the list table without opening each item; then apply changes across multiple items at once.
- **Export and sync options:** export filtered data to CSV for reporting or backups, and sync with Google Sheets (Pro) for two-way editing.
- **Developer friendly:** extend SheetsPilot with hooks and filters, register custom column types and integrate with third-party plugins. Save column layouts to PHP for version control.

== AI automation examples ==

SheetsPilot's AI assistant isn't just for writing product descriptions; it can automate nearly any content or media task inside WordPress.  These examples show how you can use AI to streamline your workflow:

- **Edit images with AI prompts:** quickly remove backgrounds, delete watermarks or text, add new objects like flowers or furniture, remove unwanted elements, sharpen blurry photos, improve lighting or swap dull skies for vivid ones.  No need for external photo editors.
- **Generate SEO titles and meta descriptions:** automatically write search-optimized titles and descriptions for hundreds of posts by referencing other columns, categories or custom fields.  For example, include a city taxonomy value in every title to boost local SEO.
- **Translate content inline:** translate posts, pages, products and custom field values directly within the table view.  This makes managing multilingual WordPress sites fast and keeps all editing in one place.
- **Adjust text length without changing meaning:** shorten long paragraphs or expand short descriptions to create consistent card sizes and layouts.  Maintain the original message while matching character counts across items.
- **Change image ratios intelligently:** convert images to square, vertical or landscape ratios by expanding the canvas rather than cropping the subject.  Ideal for featured images, banners and social media graphics.
- **Enhance images automatically:** improve sharpness, clarity, brightness, contrast, recover shadows, enhance colors and reduce noise with a single click to make any photo look professional.
- **Generate ACF repeater field data:** populate complex repeater fields like FAQs, testimonials or features by generating questions and answers based on the post title or other fields.  This is perfect for sites that need structured content such as FAQ sections across many posts.
- **Bulk improve WooCommerce product content:** rewrite product titles, short and long descriptions, specifications, benefits and other product copy at scale.  Add new keywords or adjust tone across entire catalogs.
- **Automatically generate featured images:** create featured images for blog posts using the post title, your brand's visual guidelines and style rules.  Produce unique visuals for every article without manual design.
- **Assign tags, categories and taxonomies automatically:** let AI analyze each post or product and assign relevant categories, tags, attributes or custom taxonomies.  Keep your site organized and improve navigation without hand-tagging.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/sheetspilot` directory or install via **Plugins -> Add New** in WordPress.  
2. Activate **SheetsPilot** through the Plugins screen.  
3. Open **SheetsPilot** from your WordPress admin menu.  
4. Choose the post type (posts, products, events, etc.) to load data into the spreadsheet.  
5. Start filtering, editing and running bulk actions directly in the grid.

== Frequently Asked Questions ==

= What content types can I edit? =
Posts, pages, custom post types, WooCommerce products (including variations), events from The Events Calendar, categories, tags and most custom fields.  All supported fields appear as columns in the grid.

= Does it work with Advanced Custom Fields? =
Yes.  ACF groups and subfields are loaded as separate columns so you can edit complex layouts without leaving the spreadsheet.  This includes ACF fields added to WooCommerce products.

= Can I bulk edit SEO metadata? =
Absolutely.  You can view and update SEO titles, descriptions and focus keywords for **Yoast SEO**, **Rank Math** and **SEOPress**.  Filter for empty fields and fill them all in one go or generate content with the AI assistant.

= Does it support WooCommerce variable products? =
Yes.  The grid displays variable products and their variations.  You can edit variation prices, sale dates, stock status and dimensions alongside parent product fields.

= What makes SheetsPilot different from WP Sheet Editor? =
SheetsPilot offers similar spreadsheet editing but adds a built-in AI assistant, deep SEO integrations, a prompt library, improved filtering, and native support for events.  It is a robust **WP Sheet Editor alternative** with AI-powered features.

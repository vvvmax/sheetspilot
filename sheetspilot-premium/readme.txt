Pro version of the sheetspilot plugin. Allow edit content with AI

== Description ==

SheetsPilot turns your site content into a smart spreadsheet so you can manage posts, pages, products, and custom data faster and more efficiently.

Instead of opening each item separately, you can filter, edit, and update everything from one place. Apply bulk changes, manage custom fields, and automate repetitive work using AI.

Designed for speed, scale, and precision.

== Key Features ==

= Spreadsheet-Based Content Management =
Manage posts, pages, products, and custom post types in a fast table interface.

= Smart Filtering =
Find exactly what you need:
- Filter posts, pages, and products
- Filter by status, taxonomy, users, and more
- Works with custom fields

= Inline Editing =
Edit directly in the table:
- Update titles, featured images, tags, and statuses
- Edit custom fields instantly
- Copy and paste between items

= Bulk Editing =
Update multiple items at once:
- Bulk edit categories, tags, and statuses
- Apply changes across filtered content
- Save hours on repetitive work

= Custom Fields Support =
Manage metadata without switching screens:
- Supports ACF and custom fields
- Display fields directly in the table
- Keep everything visible in one place

= WooCommerce Product Management =
Manage your store faster:
- Update prices, stock, and attributes
- Edit large product catalogs easily
- Spreadsheet speed for eCommerce

= Built-in AI Assistant =
Automate your workflow with AI:
- Save and reuse prompts
- Generate titles, descriptions, and content
- Create featured images and visuals
- Set brand tone and writing style
- Apply AI actions in bulk
- Run AI directly inside the table

== Use Cases ==

- Content teams managing blog posts and pages
- WooCommerce stores updating products and pricing
- Agencies handling large content operations
- SEO teams optimizing titles, tags, and metadata
- Directory and membership sites managing custom data

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/sheetspilot` directory, or install via the plugin repository.
2. Activate the plugin through the Plugins screen.
3. Open SheetsPilot from the admin menu.
4. Start editing your content in spreadsheet view.

== Frequently Asked Questions ==

= What can I edit? =
Posts, pages, products, custom post types, taxonomies, and custom fields.

= Does it support custom fields and ACF? =
Yes, you can view and edit custom fields directly in the table.

= Can I bulk edit content? =
Yes, you can apply updates to multiple items at once.

= Does it work with products? =
Yes, you can manage product data including price, stock, and attributes.

= What does the AI assistant do? =
It helps generate content, optimize text, create images, and automate workflows using saved prompts.

= Is it beginner friendly? =
Yes, the interface is simple and works like a spreadsheet.

= Will it work on large sites? =
Yes, it is optimized for handling large amounts of content.

== Source code ==

SheetsPilot plugin JavaScript and CSS (except third-party libraries listed below) are included in human-readable form under assets/js/, assets/css/, and pro/assets/js/.

Third-party minified libraries included in this plugin:

* CodeMirror (custom bundle): human-readable source in assets/libraries/codemirror-custom/codemirror-custom.js — https://github.com/codemirror/codemirror5
* Select2: https://github.com/select2/select2
* Bootstrap: https://github.com/twbs/bootstrap
* OpenAI PHP SDK (orhanerday/open-ai): https://github.com/orhanerday/open-ai

The file assets/libraries/codemirror-custom/codemirror-custom.min.js is the minified build of codemirror-custom.js shipped in this plugin.

Drawer side-panel loader icon: assets/images/drawer-loader-icon.svg (referenced from JavaScript via sheetspilot.editor.drawer_loader_icon_url).
